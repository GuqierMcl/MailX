## 邮箱连不上或同步停了怎么办？

如果某个账号旁出现红色感叹号，点进侧栏的 **账号**，选择该邮箱并点击底部的 **验证连接**，MailX 会直接告诉你具体哪一步出了问题。常见原因有：

1. **授权码或密码失效**：改过邮箱网页登录密码后，Gmail、iCloud 等邮箱会自动作废旧的专用密码，需要去邮箱网页重新生成并更新。
2. **未开启客户端访问**：QQ、163、新浪等邮箱需在网页版设置里开启客户端收发；公司邮箱（如飞书、Lark、Microsoft 365）可能需要管理员放行第三方客户端。
3. **网络或代理不通**：如果给账号单独设置了代理，请确认代理运行正常。代理连不上时，MailX 不会自动改为直连。

## 为什么搜不到很久以前的邮件？

为了打开速度快、不占满硬盘，MailX 每个文件夹首次同步只获取最近 **30 天**的邮件，且搜索只在**这台电脑上已下载的内容**中进行（不包含还没打开过的邮件正文和附件里的文字）。如果需要找更早的历史邮件，建议去邮箱网页版搜索。

## 发信提示“结果不确定”该怎么办？

这表示发送途中网络突然中断，MailX 无法确认邮箱服务器到底收下没有。为了避免给对方发两封重复的信，MailX 不会擅自重发。请先确认对方是否收到，或去邮箱网页版的“已发送”查看，确认没发出去再回到 **发件箱** 手动重试。

## 数据存在哪？升级前如何备份？

MailX 更新后会自动整理本地数据，旧版本可能打不开新版本的数据。如果你想在升级前留一份回退备份：

1. 先**完全退出 MailX**（不要只是关闭窗口留在后台）。
2. 复制整个数据文件夹（不要只复制里面的单个数据库文件）：

| 系统 | 默认数据位置 |
| --- | --- |
| macOS | `~/Library/Application Support/MailX` |
| Windows | `%APPDATA%\MailX` |
| Linux | `~/.local/share/MailX`（或 `XDG_DATA_HOME` 下的 `MailX`） |

:::note
密码和授权码存放在系统自带的密码库里，复制上面的文件夹不会带走密码，因此它适合同一台电脑升级前留底，不适合直接拷贝到另一台电脑迁移。
:::

## 遇到问题如何反馈？

打开 **设置 → 关于**，里面有直接跳转到 [GitHub 问题反馈](https://github.com/GuqierMcl/MailX/issues) 的链接。反馈时请写上：

- MailX 版本号和你的操作系统；
- 使用的是哪家邮箱或 AI 服务商；
- 做了什么操作、遇到了什么现象。

如果需要附上诊断日志，可以在上面数据文件夹里的 `logs/` 子目录中找到 `diagnostics.jsonl`。日志只记录启动与同步状态，不含密码、邮箱地址和邮件内容，截取出错前后的一小段即可。

:::caution
公开反馈问题时，请**不要**贴出你的密码、授权码、真实邮件内容或个人邮箱地址。如发现安全漏洞，请通过仓库中的私密安全渠道报告。
:::
