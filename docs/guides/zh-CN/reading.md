添加好邮箱后，MailX 会自动同步最近的邮件，并把它们汇总在一个清爽的界面里。

## 从“此刻”开始

**此刻**在侧栏顶部，帮你一眼看清当天的重点：需要处理的异常提醒、未发完的草稿、15 分钟内收到的验证码、新邮件和最近动态。页面上的内容都在你本机计算，不会发往任何服务器。

- 点击任意一条即可直接打开对应邮件或草稿。
- 鼠标移到某个板块标题右侧，点 **···** 可以选择 **今天隐藏**（有新内容时会自动回来）或 **不再显示**。
- 在 **设置 → 外观 → 此刻** 中，可以把隐藏的板块重新打开，或把顺序从“自动”改为“固定”并拖动排序。
- 如果习惯一打开软件就进收件箱，可以在 **设置 → 通用 → 启动时打开** 中修改。

## 统一收件箱与单账号文件夹

- 侧栏上方汇总了所有账号的 **收件箱**、**星标**、**草稿** 和 **已发送**，**更多** 里包含归档、垃圾邮件和废纸篓。
- 侧栏下方列出每个独立的邮箱账号，展开后可以看到该账号在服务器上的全部文件夹。
- 想让阅读空间更宽敞？点标题栏的折叠按钮或按 `Cmd/Ctrl + B`，侧栏会收成一列图标。
- 每个文件夹首次同步默认获取最近 **30 天**内最新的邮件（最多 1,000 封）。打开过的邮件正文会保存在你的电脑上，没有网络时也能随时翻看。

## 日期分组、视图布局与对话阅读

- **按日期分组**：邮件列表和搜索结果默认按本机日期分为 **今天**、**昨天**、**本周**、**上周** 和 **更早**（“今天”和“昨天”优先）。在 **设置 → 外观 → 邮件列表** 中可以修改 **每周第一天**，或关闭 **按日期分组** 恢复平铺列表。
- **分屏与单栏**：默认采用 **分屏视图**（左列表、右正文，可拖动中间分隔调整宽度）。喜欢更专注的阅读体验，可在 **设置 → 外观 → 邮件列表** 切换为 **单栏视图**，按 `Esc` 返回列表。
- **整段对话**：来回回复的邮件会自动串成一段对话，当前邮件完整展开，其余来信和你自己的回复排在上下方，点一下就能切换。阅读区顶部随时可以切回 **单封** 模式。
- **折叠旧引用**：回复末尾附带的历史引用会自动收进 **显示引用内容** 按钮，让新内容更突出；再次回复或转发时仍会保留完整原文。

## 快速整理与批量处理

鼠标移到邮件行上（或用右键菜单）可以快速执行常用操作：

- **星标 / 标为已读或未读**：改动会自动同步回邮箱服务器。
- **归档**：把邮件从收件箱收起来，之后可在 **更多 → 归档** 里找到。
- **删除**：先给一小段撤销时间，随后移入服务器的废纸篓；在废纸篓里再次删除会提示确认并永久移除。
- **按联系人查看与聚合**：右键某封邮件，选 **查看此联系人的邮件** 可只看他的所有来信；选 **聚合此联系人的邮件** 会把这个发件人的邮件在收件箱里合并成一行，之后可在 **设置 → 联系人** 取消。
- **批量操作**：点击列表顶部的 **选择**，或按住 `Cmd/Ctrl` / `Shift` 选中多封邮件（单次最多 500 封），即可批量标已读、加星、归档或删除。

:::note
**归档**和**按联系人聚合**目前只保存在你这台电脑上，不会影响网页版或其他设备上的邮件位置。
:::

## 验证码一键复制

收到登录或校验验证码时，不用打开邮件慢慢选字：

- **在邮件列表里**：识别到验证码的邮件会直接显示 **复制验证码** 按钮，点一下就复制，不会把邮件标为已读。
- **在阅读区顶部**：打开邮件后，正文上方也会出现醒目的验证码条和复制按钮。
- **在系统通知里**：开启通知内容显示后，macOS 和 Windows 可以直接在弹窗通知上点 **复制验证码**（MailX 需保持在后台运行）。
- **复制后自动清理**：如果不想收件箱堆满过期验证码，可在 **设置 → 邮件 → 增强** 中开启 **复制验证码后将邮件移至废纸篓**（带 5 秒撤销，绝不会永久删除）。

## 搜索、图片与附件

- **搜索**：按 `/` 快速搜索，支持查找本机已同步邮件的标题、发件人、预览、已下载的正文和附件名称。还没下载正文的老邮件和附件内部文字暂时搜不到。
- **网络图片**：为了防止追踪，邮件中的远程图片默认先询问，你允许后再加载。
- **保存附件**：在阅读区点击附件即可保存到电脑本地。
