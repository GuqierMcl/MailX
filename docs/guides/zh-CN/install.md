---
title: 安装与更新
description: 在 macOS、Windows 和 Linux 上安装 MailX，并保持版本最新。
---

在[下载页](/zh-CN/download/)选择适合你电脑的安装包，下载后打开即可安装。

## 在你的系统上安装

### macOS

- **Apple 芯片**（M 系列）与 **Intel 芯片**对应不同的安装包。不确定怎么选？点屏幕左上角的苹果菜单 → **关于本机**，看“芯片”或“处理器”一栏。
- 安装包已通过 Apple 公证，下载后可以直接打开。

### Windows

- 适用于 64 位 Windows，运行安装程序按提示完成即可。
- **x64**（Intel / AMD）与 **ARM64**（骁龙等）对应不同的安装包。不确定怎么选？打开 **设置** → **系统** → **系统信息**，看“系统类型”一栏。ARM64 安装包从较新的版本开始提供。
- 首次打开时如果出现蓝色的安全提示，点 **更多信息** → **仍要运行**。

### Linux

64 位 Intel 或 AMD 处理器请选择 **x64**，64 位 ARM 处理器请选择 **ARM64**。可以在终端运行 `uname -m` 查看，输出 `x86_64` 对应 x64，`aarch64` 对应 ARM64。

请在下载页查看你的架构可用的安装格式，包括 **AppImage**、**deb**（Debian / Ubuntu）和 **rpm**（Fedora / openSUSE）。从提供 ARM64 安装包的版本起，Ubuntu 上两种架构均请使用 24.04 或更新版本。

- **AppImage**：下载后即可运行，支持在应用内直接更新。
- **deb / rpm**：通过系统的软件包管理器安装；有新版本时会收到提醒，需要手动下载安装。

## 保持更新

MailX 启动后和运行期间会自动检查新版本，你可以在 **设置 → 关于** 管理更新方式。

- **自动更新（默认开启）**：新版本下载完成后，你可以选择 **立即重启**，也可以继续手头的工作，等下次完全退出 MailX 时自动完成安装。MailX 不会突然自己重启。
- **手动检查**：点击 **检查更新** 即可立刻查看是否有新版本。如果关闭了自动更新，有新版本时可以先看更新内容，再决定是否下载。

:::note
关闭窗口让 MailX 留在后台时不会安装更新，需要完全退出应用才会完成升级。macOS 首次从早期未签名版本升级到签名版本时，系统会弹窗请求访问钥匙串，选 **始终允许** 即可。
:::

想在升级前留一份本地数据备份？请看[常见问题与排查中的备份说明](/zh-CN/docs/troubleshooting/#数据存在哪升级前如何备份)。
