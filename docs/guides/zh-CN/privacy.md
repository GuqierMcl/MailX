MailX 没有自己的邮件服务器。你的邮件和密码保存在你自己的电脑上，我们看不到，也不收集使用数据。

## 保存在你的电脑上

- **邮件**：邮件列表、已下载的邮件、草稿和附件都保存在本机。MailX 不会另外加密这些文件，请为电脑设置登录密码。
- **密码和密钥**：保存在系统自带的密码库中（macOS 钥匙串、Windows 凭据管理器、Linux 的 Secret Service），保存后不会再显示出来。
- **AI 对话、邮件摘要和译文**：保存在本机。

## MailX 会连接哪些地方

| 连接 | 什么时候 | 发送什么 |
| --- | --- | --- |
| 你的邮箱服务商 | 收信、发信和登录时 | 登录信息和你的邮件 |
| 微软登录页 | 添加 Outlook 或 Microsoft 365 账号、保持登录时 | 登录信息；密码只在浏览器里输入 |
| GitHub | 启动时和运行期间检查更新；自动下载可以关闭 | 不包含邮件内容 |
| 翻译服务 | 你同意并使用翻译后 | 邮件的主题和文字 |
| 你添加的 AI 服务商 | 你同意并使用 AI 后 | 见下方说明 |
| models.dev | 打开 AI 设置时 | 下载 AI 服务商和模型的公开目录与图标，不包含邮件内容和密钥 |
| 邮件中的图片 | 默认先询问 | 向图片所在的网站请求图片 |
| 发件人头像 | 默认关闭 | 向 Gravatar 发送发件人地址的哈希值；向 DuckDuckGo 或 Google 发送发件人的域名 |

## AI 会发送什么

首次使用前，MailX 会征求你的同意。之后，为了完成你的要求，会发送你输入的内容，以及用到的邮件或草稿的文字、主题、发件人、收件人、日期和附件名称。AI 助手会按你的问题查找和阅读邮件，所以可能用到多封；你可以在设置中限定它能读哪些邮箱。附件里的内容和图片不会发送。

如果你打开“打开邮件时自动总结”或指定了总是总结的发件人，打开这些邮件时会自动发送。这些选项默认关闭。

使用 Ollama 等运行在本机的模型时，邮件内容只发给这台电脑上的模型。你可以随时在设置中撤回同意。

每个邮箱账号可以单独设置代理。代理连不上时，MailX 会停止连接，不会悄悄改为直连。

## 让其他 AI 工具访问邮件

MailX 可以让这台电脑上的其他 AI 工具读取和处理邮件，默认关闭。开启后，连接的工具可以访问所有账号、管理草稿、添加和导出附件，并且可以直接发信，不会逐封询问；这些工具可能把邮件内容发给它们自己的 AI 服务商。它们不能删除邮件。在设置中关闭即可停止访问。
