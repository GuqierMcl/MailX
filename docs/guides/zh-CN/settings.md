在主窗口按 `Cmd + ,`（macOS）或 `Ctrl + ,`（Windows / Linux），或从应用菜单进入 **设置**，就能按自己的习惯调整 MailX。

## 外观与界面

在 **设置 → 外观** 中可以调整：

- **浅色 / 深色模式与主题色**：跟随系统或手动切换，也可以自定义界面强调色。
- **邮件列表**：切换 **分屏视图** / **单栏视图**、开关 **按日期分组**、选择 **每周第一天**，以及决定跨账号视图里用邮箱名称还是小图标标识所属账号。
- **“此刻”页**：重新打开已隐藏的板块，或切换为固定顺序并拖动排列。

## 通知与未读角标

在 **设置 → 通知** 中可以控制提醒方式：

- **显示通知内容**：开启后，新邮件弹窗会显示发件人、主题，以及识别到的验证码快捷复制按钮；如果不想在锁屏或共享屏幕时露出内容，关掉它即可。
- **应用图标未读角标**：在 macOS 程序坞和支持的 Linux 桌面启动器上显示统一收件箱的未读数，可关闭或只统计特定账号（Windows 暂不支持）。

## 后台运行与开机自启动

在 **设置 → 通用** 中：

- **关闭主窗口时**：默认每次询问你是留在后台还是退出，也可以设为固定行为。留在后台时，MailX 仍会及时提醒新邮件并保持外部 AI 工具连接。
- **开机自启动**：默认关闭。开启后还可以勾选 **静默启动**，开机时自动在后台静静收信，不弹出主窗口。
- **菜单栏图标（macOS）**：默认开启，随时可以从顶部菜单栏快速唤出窗口。

## 常用快捷键

在主窗口非输入状态下，可以直接用键盘快速处理邮件（随时按 `?` 查看完整列表）：

| 快捷键 | 作用 |
| --- | --- |
| `J` / `↓` | 下一封邮件 |
| `K` / `↑` | 上一封邮件 |
| `Enter` / `O` | 打开列表第一封邮件 |
| `/` | 搜索邮件 |
| `E` | 归档（或移回收件箱） |
| `S` | 加星 / 取消星标 |
| `U` | 标为已读 / 未读 |
| `#` / `Delete` | 删除邮件 |
| `R` / `A` / `F` | 回复 / 全部回复 / 转发 |
| `Cmd/Ctrl + B` | 折叠或展开左侧栏 |
| `Cmd/Ctrl + J` | 打开或关闭 AI 助手（写信时呼出 AI 写作菜单） |
| `Cmd/Ctrl + ,` | 打开设置 |
| `Esc` | 返回列表 / 退出多选 / 停止 AI 回复 |
| `?` | 显示全部快捷键 |

:::tip
如果你使用语音输入或辅助工具，怕误触单键快捷键，可以在 **设置 → 快捷键** 中关闭单键快捷键（带 `Cmd/Ctrl` 的组合键和 `Esc` 仍会保留）。
:::
