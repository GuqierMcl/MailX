---
title: Appearance, notifications & shortcuts
description: Customize theme and layout, control notifications and background behavior, and view keyboard shortcuts.
---

Press `Cmd + ,` (macOS) or `Ctrl + ,` (Windows / Linux), or open **Settings** from the app menu, to tailor MailX to your workflow.

## Appearance and layout

Under **Settings → Appearance**:

- **Theme and accent color**: follow your system theme or pick light/dark mode, and choose a custom accent color.
- **Message list**: switch between **Split view** and **Single pane**, toggle **Group by date**, pick the **First day of the week**, and choose whether multi-account views show a mailbox name or a small account icon.
- **Now**: bring back hidden sections, or switch to a fixed order and drag sections where you want them.

## Notifications and unread badge

Under **Settings → Notifications**:

- **Show notification contents**: shows senders, subjects and quick-copy verification code buttons in system notifications. Turn this off if you prefer private notifications on lock screens or during screen sharing.
- **App icon badge**: shows the unified inbox unread count on the macOS Dock and supported Linux launchers. Turn it off or pick which accounts count under **Settings → Notifications → App icon badge** (not yet available on Windows).

## Running in the background and launch at login

Under **Settings → General**:

- **When closing the main window**: asks by default whether to keep running in the background or quit, or you can set a fixed choice. Staying in the background keeps new-mail alerts and external AI tool connections working.
- **Release UI memory in background**: off by default. When enabled, closing the main window to the background or starting silently keeps only the mail core running to lower memory usage; reopening the window reloads the interface and takes slightly longer.
- **Launch at login**: off by default. When enabled, you can also turn on **Start silently** so MailX starts quietly in the background.
- **Menu bar icon (macOS)**: on by default so you can reopen MailX from the top menu bar anytime.

## Keyboard shortcuts

When you are not typing in a text box in the main window, press `?` anytime to see every shortcut:

| Shortcut | Action |
| --- | --- |
| `J` / `↓` | Next message |
| `K` / `↑` | Previous message |
| `Enter` / `O` | Open the first message |
| `/` | Search mail |
| `E` | Archive (or move back to inbox) |
| `S` | Add or remove star |
| `U` | Mark read or unread |
| `#` / `Delete` | Delete message |
| `R` / `A` / `F` | Reply / Reply all / Forward |
| `Cmd/Ctrl + B` | Collapse or expand the sidebar |
| `Cmd/Ctrl + J` | Open or close the AI assistant (or AI writing menu while composing) |
| `Cmd/Ctrl + ,` | Open Settings |
| `Esc` | Return to list / exit selection / stop AI reply |
| `?` | Show all shortcuts |

:::tip
If you use voice input or assistive tools and want to avoid accidental presses, turn off single-key shortcuts under **Settings → Keyboard shortcuts**. Shortcuts with `Cmd/Ctrl` and `Esc` keep working.
:::
