# 接口草案

状态：**桌面应用 IPC 与本地 MCP 已有实现 / HTTP 与远程 MCP 为 Draft，接口未冻结**。本目录记录账号、同步、邮件读取与整理、草稿、发送队列、桌面设置及本地 MCP 的当前契约，并区分后续设计。应用版本与开发者接口的兼容承诺分别管理，接口兼容策略需另行明确。

| 文档 | 范围 |
| --- | --- |
| [应用 API](app-api.md) | Tauri / Web 共用 DTO、命令、事件、错误和发送幂等 |
| [MCP](mcp.md) | 外部工具、连接生命周期、授权和远程扩展 |

应用 TypeScript DTO 由 Rust 经 ts-rs 生成并检查产物漂移；MCP 工具 schema 由共享工具层的 `ToolDescriptor` 生成。文档中的 `v1` 表示拟定命名空间，不表示已经发布稳定 API。对外兼容策略需另行明确；修改开发期契约时同步更新实现、调用方和验证。
