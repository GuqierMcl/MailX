# AI Runtime 初始设计

状态：**Initial draft** · 原生 Rust 是本轮建议，可随工作流复杂度重新选型；不代表永久排除独立 Runtime。

## 1. 首批能力

初版以固定、用户触发的工作流验证价值：邮件 / 线程摘要、待办建议、回复草稿和语气改写。自动分类、向量语义检索、任意工具循环与第三方 MCP Client 留到后续。

待办结果只是当前界面的建议列表，不自动创建外部任务；邮件里的日期可能不完整，输出原始依据、推断时区和不确定状态，不擅自补一个确定截止日。AI 关闭、离线或失败时，收发和本地搜索继续可用。

## 2. 模型适配

核心定义 `ModelProvider` 端口，infra 实现 OpenAI 兼容 HTTP 流接口与 Ollama 原生接口。两类适配器分别解析流与错误，不能假设所有提供商支持相同参数、工具调用或 JSON 输出。具体 API 版本与 SDK 在 M3 对接时核验。

模型配置包含 providerId、baseUrl、modelId、secretRef、routeId、超时及可选上下文预算。所谓“兼容接口”先通过真实请求测试才标记可用。Anthropic 原生协议单独适配，不把一个 Key 输入框当作已经支持所有模型。

前端只调用 MailX 核心，不直接请求模型或保存 Key。用户可以输入 Key，后台保存后前端只得到已配置状态；本地端点由用户启用，不启动即扫描模型服务。

## 3. 上下文与数据披露

每次运行固定 `contextRefs`：选定 emailId / thread 内具体邮件集合、草稿 revision、用户指令和模型配置。默认只发送正文纯文本、必要主题 / 发件显示信息和用户选择内容，不上传整个收件箱或附件二进制。

云模型首次使用时说明提供商与内容范围；后续可采用“该账号允许该提供商处理我主动选择的邮件”的可撤销设置。扩大账号、批量处理或加入附件需重新确认范围。模型端点变更不能悄悄沿用对旧接收方的授权。

邮件正文和工具结果始终以不可信引用材料组织，不能更改系统策略。首版工作流不配发信、执行命令、访问任意 URL 或读取其他账号的工具。输出先验证结构，再展示为建议；待办条目应带 sourceEmailId / 依据片段，便于回看。

## 4. Run 生命周期

```text
created → awaitingConsent → preparing → streaming → completed
                              │           ├── failed
                              │           └── canceled
                              └── failed / canceled
进程中断的非终态 → interrupted
```

已存在有效披露授权时跳过 `awaitingConsent`。记录 runId、kind、provider / model、上下文引用与摘要、输入 revision、状态、累积输出和错误。流式 chunk 附单调序号；前端掉线后查 Run 快照，应用重启不自动重新请求收费模型。

取消应向 HTTP 流传播，停止追加展示；可能已经产生的提供商计费不能保证撤回。部分输出保持“未完成”标记，不自动写成完整草稿。建议应用到草稿时检查输入 revision，已被用户修改则提供比对 / 新建版本，不覆盖现有编辑。

缓存摘要的键至少包括所选邮件内容摘要、模型、提示模板版本和语言；源内容或选择集合变化后失效。不同账号或授权范围不复用可能披露更多内容的缓存。

## 5. 初始资源预算

- 全实例最多 2 个活跃 Run，同一编辑器只允许一个写作 Run；排队可取消。
- 默认输入最多 32,000 Unicode 字符，输出最多 2,000 token，并受模型实际上下文限制；不足时明确缩小选区或分段，不能静默截掉关键邮件。
- 流首包超时初案 30 秒，总时限 120 秒，可按本地模型配置调整。超时显示当前部分结果与可重试提示，不无限自动重试。
- 为每个提供商记录可用时返回的用量；不把估算费用当成账单。精确价格不硬编码在启动设计中。
- 完整提示词不另存审计日志；Run 结果属于敏感邮件派生数据，支持用户删除，与账号清理联动。

这些值是实现起点，M3 以真实模型和本地硬件测量后再定。`awaitingConsent` 和 provider 错误不能卡住主工作台。

## 6. 首轮验收

至少覆盖一个云端兼容模型和一个本地 Ollama 模型；验证摘要、结构化待办、流式拟信、取消、超时、截断提示、重启恢复、草稿版本冲突和恶意邮件提示词。核心边界是“只访问用户选定内容、结果可核对、不能自主发送”。
